🩺 檢查LOG

🩺 Centimani 運行日誌與檢查LOG

  • 雙模輸入：支援幾百 KB 大檔 Log / CSV 直接選檔，或短文字直接貼上。
  • FAIL 事故定位：秒抓通訊埠不存在、Dictionary 重複鍵、超時或數值超標。
  • PASS 節拍分析：自動解析各 Phase 耗時、Top 5 瓶頸排行與 CT 縮短建議。
  • 解法導引：提供真實機台排查步驟與一鍵「無硬體試跑 (Dry-Run)」對策。

🏷️ 代碼速查

🏷️ TestID / Error Code 速查與精準套用

  • 官方字典檢索：依中英文關鍵字搜尋 Test Item Code V2.04，支援僅顯示通用碼。
  • 方案一（母體積木）：直接替換「母體產生」已勾選積木的指定步驟 TestID。
  • 方案二（現有 Excel）：列出載入腳本的測試列，一鍵填入 TestID 並簽章存檔。
  • 方案三（複製與暫存）：支援單欄/雙欄複製（Description + Tab + TestID）與暫存籃。

  • 同步比對同目錄 System.ini 的 Checksum 一致性。

💾 產線修復匯出

  • 依下方勾選的修復方案自動修補異常項目。
  • 輸出 *_FIXED.xlsx 至原測試包資料夾。
  • 自動更新 System.ini 的 [Checksum] 供實機載入。

🧪 無硬體試跑轉換

  • 清空 Instrument / Switch 的 Mount 掛載設定。
  • 硬體控制與量測列轉為 ExecMode = 6（Skip）。
  • :Sf* 指令維持 8/9 並清空 Validation，供無儀器 PC 驗證流程。
